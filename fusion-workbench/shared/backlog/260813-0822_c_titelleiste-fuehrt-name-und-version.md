# Die Titelleiste führt links Namen und Version, und dafür kommen semantische Versionstags

**Filed by:** k1

KRK sollte in der Titelleiste, wo im Moment nur der Pfad steht, links den Namen mit Version führen, also "KRK <1.0.0>". Dafür müssen zugleich semantische Versionstags eingeführt werden. Beides gehört in einen Zug: eine Version anzeigen, die nirgends verbindlich festgelegt ist, wäre eine Zahl ohne Deckung.
