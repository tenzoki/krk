# Die Vorschau nutzt ein Default-Profil, das für einen Ordner die Anzahl der Dateien und Unterordner zeigt

**Filed by:** k1

Das Vorschauverhalten der Dateiliste soll ein Default-Profil nutzen, das greift, wenn kein anderes Leseprofil greift. Dieses Default-Profil trägt eine Regel für den Fall, dass die Zeilenmarke auf einen Ordner trifft: dann zeigt die Vorschau zusätzlich zu den heute angezeigten Metadaten die Anzahl der Dateien (Anzahl der versteckten Dateien in Klammern) und die Anzahl der Unterordner (versteckte Unterordner ebenfalls in Klammern).
